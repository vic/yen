These are small projects for you to copy and grow. The examples in these docs show one idea each;
a template is a whole project. Each one here is evaluated in our CI.


| Template | What it is | Start |
|---|---|---|
| `flake-parts` | yen inside flake-parts | `nix flake init -t github:vic/yen#flake-parts` |
| `minimal` | yen: one NixOS host | `nix flake init -t github:vic/yen#minimal` |
| `multi-platform` | yen: NixOS, nix-darwin and home-manager in one fleet | `nix flake init -t github:vic/yen#multi-platform` |
| `noflake` | yen: one NixOS host, without flakes | copy `templates/noflake`, then `nix-build -A nixosConfigurations.laptop.config.system.build.toplevel` |

Not sure which one? Take `minimal`, then read [Getting started](/start/getting-started/).
`templates/fleet` is the showcase fleet. Read it, but do not start from it: its `yen` input is this repository.
