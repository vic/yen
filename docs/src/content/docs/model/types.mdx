yen has no type system of its own. A type is any value with `check = value: bool`.
`lib.types` from nixpkgs works, a [kind](/model/kinds-fields/) works (see [Instances and refs](/model/instances-refs/)),
and `yen.lib.is` makes a type from any function.


| Constructor | Default |
|---|---|
| `yen.lib.str`, any type | none: the field is required |
| `yen.lib.opt type value` | `value` |
| `yen.lib.maybe type` | `null` |
| `yen.lib.derive type (self: …)` | computed from the instance itself |
| `yen.lib.is (v: …)` | none: a type from a check function |
| `yen.lib.listOf type` | none: a list whose elements pass the type |
| `yen.lib.attrsOf type` | none: an attrset whose values pass the type |
| `yen.lib.enum [ … ]` | none: one of the listed values |

:::caution[WARNING: use `yen.lib.listOf` and `yen.lib.attrsOf`, not nixpkgs]
nixpkgs `listOf` and `attrsOf` check only the outer shape. Their items are checked in `merge`, which yen
never calls. So `(nixpkgs.lib.listOf x).check [ "a" ]` is `true` when `x` is an int, and the same holds for
`attrsOf`. `yen.lib.listOf` and `yen.lib.attrsOf` check every item: the shape when a field reads the value, the
items in `result.deep`. See
[the caution on nixpkgs composite types](/principles/modules/#types-anything-with-check).
:::

```nix title="modules/host.nix" {13-14}
# A type is anything with `check = value: bool`. yen adds defaults on top of it.
{ yen, lib, ... }:
let
  inherit (yen.lib)
    opt
    maybe
    derive
    is
    ;
in
{
  yen.kinds.host.fields = {
    addr = yen.lib.str; # required
    port = opt yen.lib.port 22; # a default
    jump = maybe yen.lib.str; # null by default
    vpn = derive yen.lib.str (self: "vpn-${self.name}"); # a default computed from the instance
    tags = opt (is (v: builtins.isList v && builtins.all builtins.isString v)) [ ]; # your own check
    labels = opt (yen.lib.attrsOf yen.lib.str) { }; # an attrset whose values are strings
    settings.kernel.channel = opt (yen.lib.enum [
      "lts"
      "latest"
    ]) "lts"; # one of a list, and a nested field
  };
}
```

Fields can nest. `settings.kernel.channel` is one field at a path, with its own type and default.
An instance gives only what it needs:


```nix title="modules/hosts.nix"
{ yen, ... }:
{
  yen.host.web.addr = "10.0.0.1";
  yen.host.db = {
    addr = "10.0.0.2";
    port = 2222;
    vpn = "vpn-database"; # an explicit value wins over `derive`
    labels.role = "database";
    settings.kernel.channel = "latest";
  };
}
```

The read of a field looks at the instance first, then at the default, then checks the value:


```nix title="result"
{
  db = {
    channel = "latest";
    jump = null;
    labels = {
      role = "database";
    };
    port = 2222;
    tags = [ ];
    vpn = "vpn-database";
  };
  web = {
    channel = "lts";
    jump = null;
    labels = { };
    port = 22;
    tags = [ ];
    vpn = "vpn-web";
  };
}
```

A value that fails its type is an error record that names the field. A field reads only the shape of its
value: a list, an attrset, a function. The parts are checked later, by `result.deep`, after the fleet
evaluated: so building one host never forces the list elements of another, and a part that throws is an
error record, not a crash. `nix flake check` fails on both (`checks.<system>.yen-lean`):


```nix title="variants/bad-values.nix"
# A channel that is not in the list, and a label that is not a string.
{ yen, ... }:
{
  yen.host.cache = {
    addr = "10.0.0.3";
    settings.kernel.channel = "stable";
    labels.owner = 1;
  };
}
```

```nix title="result"
[
  {
    class = "fixable";
    code = "check";
    error = "settings.kernel.channel fails its check";
    fix = "give settings.kernel.channel a value of type one of \"lts\", \"latest\"";
    from = "host:cache";
    got = "stable";
    path = [
      "settings"
      "kernel"
      "channel"
    ];
    want = "one of \"lts\", \"latest\"";
  }
]
```

```nix title="result"
[
  {
    class = "fixable";
    code = "deep";
    error = "labels.owner: a part is not a string";
    from = "host:cache";
    path = [
      "labels"
      "owner"
    ];
    want = "a string";
  }
]
```

:::note[Derived defaults]
`derive` gets the instance as `self`, so a default can read other fields or the instance name.
An explicit value always wins: `db` sets its own `vpn`.
:::
